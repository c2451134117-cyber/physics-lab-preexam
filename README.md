# physics-lab-preexam

大学物理实验预习的 Tampermonkey 用户脚本。本仓库保留两套互不干扰的脚本：

| 适用网站 | 安装的脚本 | 答案来源 |
| --- | --- | --- |
| 旧科大奥锐平台 `172.31.80.14:7101` | `physics-lab-preexam.user.js` | 页面 `NewContentXml` 的 `StdAnswer` |
| 深圳大学新平台 `172.25.75.220` | [`physics-lab-preexam-szu.user.js`](physics-lab-preexam-szu.user.js) | 12 份满分阅卷 PDF 校对出的 [`szu-reviewed-bank.json`](szu-reviewed-bank.json) |

## 深圳大学新平台

将 `physics-lab-preexam-szu.user.js` 导入 Tampermonkey，正常登录后进入某个实验的答题页。脚本会自动读取当前试卷，逐题核对题号、题型、题干及完整选项集合，再把选项文本映射到当前试卷的 A/B/C 等代号，最后自动提交一次。题目和选项随机排序不会影响匹配。

该题库有 12 个实验、218 道题，来自对应实验得分 100/100 的阅卷 PDF。PDF 中少数数学公式没有可提取的文本，已查看渲染页并按公式内容核对。PDF 文件本身包含姓名和学号，**未上传到仓库**；题库只包含题目和选项。

防重复规则：列表中的实验必须未提交、当前试卷剩余次数必须为 3，且本浏览器尚无该账号与实验的提交锁。提交前先在 IndexedDB 写入锁；如果网络结果不明，不自动重试。换浏览器、清除网站数据或手动提交不受此本地锁约束，服务端记录是最终依据。

若试卷内容变化、题库不完整、认证失效或请求失败，脚本停止并在页面右下角显示原因，不消耗提交机会。**安装后进入答题页会自动提交**，请先确认确实要使用这一次机会。

脚本使用当前登录会话的 `Authorization: Bearer` 令牌，只访问当前学生的预习列表、试卷和提交接口；不包含用户名或密码，不访问教师或管理员接口。该校内站点目前使用 HTTP，校外访问请遵循学校提供的校园网接入方式。

## 维护和验证

修改题库后，使用 Node.js 生成内嵌题库的脚本并执行离线验证：

```bash
node scripts/build-szu.mjs
node --check physics-lab-preexam-szu.user.js
node tests/szu.test.cjs
```

离线验证覆盖 218 道题在题目与选项乱序下的映射，以及缺题、题干或选项变化、提交次数不足时的停止逻辑。未在真人账号上执行新脚本的自动提交测试，以免额外消耗提交机会。

旧平台脚本及原用法继续保留。本项目仅供个人学习使用，请遵守学校规定。
